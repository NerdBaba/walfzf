# Project Structure

This document describes the layout and key components of the walfzf project.

## Directory Layout

```

```

## Key Files

### `walfzf`

The main Bash script that implements the wallpaper search and download tool. It is a single-file application (~900 lines) with the following structure:

- **Configuration handling**: Loads and creates config file at `~/.config/wallhaven-cli/config.sh`
- **Dependency checking**: Ensures required tools (bash, curl, jq, fzf, file) are available
- **API functions**: Communicates with the Wallhaven.cc API (`/api/v1/`)
- **Command functions**: Implements each subcommand (`search`, `latest`, `toplist`, `random`, `tags`, `download`, `collection`, `edit`, `setup`, `help`)
- **Interactive selection**: Uses `fzf` for fuzzy searching and previewing wallpapers
- **Image preview**: Supports terminal image previews via kitty or chafa
- **Download logic**: Saves wallpapers to a configurable directory

### `install.sh`

A helper script that installs walfzf to `~/.local/bin`. It checks dependencies, copies the main script, and provides PATH guidance.

### Configuration

When first run, walfzf creates a configuration file at `~/.config/wallhaven-cli/config.sh` with default settings. Key configuration options include:

- `CONFIG_EDITOR`: Default text editor
- `CONFIG_SAVE_FOLDER`: Directory where wallpapers are saved
- `CONFIG_TEMP_FOLDER`: Temporary directory for caching previews
- Search parameters: categories, order, time range, resolutions, ratios, preloading

### Dependencies

- **Required**: bash (>= 4.x), curl, jq, fzf, file
- **Optional**: kitty or chafa (for image previews)

## Development Notes

- The project uses a single Bash script for simplicity
- No external dependencies beyond standard Unix tools
- Configuration is stored in a shell script that is sourced at runtime
- The script uses the Wallhaven API (https://wallhaven.cc/help/api) for all data fetching
- Interactive previews are implemented using fzf's preview window feature
